Base URL & Authentication

Base URL

Protected Header
Authorization: Bearer <accessToken>
Content-Type: application/json

Refresh Flow

// On every API call:
if (accessToken expired) {
  newTokens = POST /auth/refresh
  store(newTokens)
  retry original request
}
if (refreshToken expired) {
  redirect to login screen
}
Never store tokens in localStorage, AsyncStorage (unencrypted), or plain SharedPreferences. Both tokens must be cleared on logout.

Auto-Renewal — How It Works

The server runs a cron job every day at 00:05 AM. No action needed from the mobile app.
StepWhat Happens
1. Cron firesFinds all subscriptions with status=ACTIVE, autoRenew=true, and endDate ≤ now
2. Extend end dateAdds plan.durationDays to current endDate
3. Log renewalCreates SubscriptionRenewalLog entry with old/new dates and amount
4. Create paymentCreates a PENDING payment — staff must manually mark it COMPLETED
The app should show a notification / badge for pending payments so staff can collect fees on renewal day.
